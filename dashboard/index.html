EXECUTION BOUNDARIES

Protection before permission.

  • Actual paper and live order execution remains disabled.
  • Verified synthetic broker evidence is not an IBKR login.
  • Real TWS / Gateway authentication and data validation remain unavailable here.
  • Maximum 25 contracts per strike; 125 across five strikes.
  • Risk limits and permitted accounts cannot be changed in this interface.

An expired dashboard session does not switch off independent supervision. It also does not prove orders canceled or positions closed.

Keys & recovery

Every change requires a fresh login-key verification. Keep a recovery-only key offline. Key changes revoke dashboard sessions and trading grants; independent protection continues.

Revocation requires a different surviving login key. A recovery-only key cannot log in or authorize trading.
